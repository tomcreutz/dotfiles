# Work backlog

This directory contains implementation-ready work items for coding agents.

## File convention

- Use one Markdown file per work item.
- Prefix files with a stable three-digit sequence number.
- Keep the item updated as decisions, progress, blockers, and validation results
  change.
- Do not remove completed items; set their status to `done` so the decisions and
  validation record remain available.

## Status values

- `planned`: ready to be picked up
- `in-progress`: actively being implemented
- `blocked`: waiting on a decision, dependency, or external change
- `done`: implemented and validated
